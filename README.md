# 🌷 Bloom Journal — A Little Space to Grow

*A cozy digital garden for your thoughts, moods, and daily habits.*

Bloom Journal is a responsive journaling and mood-tracking website designed to help you reflect on your day, understand your emotions, and build small, meaningful habits. With its calming cottage-garden aesthetic, it offers a peaceful space to slow down and celebrate personal growth.

## 🌿 Live Demo

**Live Website:** `https://YOUR-USERNAME.github.io/bloom-journal/`

*Replace `YOUR-USERNAME` with your GitHub username after deploying the project.*

## ✨ Features

### 📔 Personal Journal
- Create, edit, and delete journal entries.
- Add custom titles, dates, and personal reflections.
- View saved entries in an organized list.
- Automatically save entries in browser storage.

### 🌸 Mood Tracker
- Track five moods: Happy, Calm, Okay, Sad, and Tired.
- Associate moods with specific dates.
- View mood emojis directly on the calendar.
- Receive gentle, mood-related reminders.

### 🗓️ Interactive Mood Calendar
- Navigate between months.
- Select any date to record your mood or write a journal entry.
- Identify today's date and your currently selected date.
- Review mood history visually.

### 🌱 Daily Habit Tracker
- Add your own daily habits.
- Rename and delete habits.
- Mark habits as completed for individual dates.
- View daily progress through a progress bar.

### 📊 Personal Dashboard
- Total number of journal entries.
- Today's mood.
- Daily habit completion.
- Number of unique days with journal entries.

### 🌙 Personalization
- Light and dark themes.
- Daily inspirational messages.
- Cottage-garden colors featuring sage green, floral pink, and ivory.
- Responsive layout for desktop, tablet, and mobile devices.

### 💾 Local Data Persistence
- Saves journal entries, moods, habits, and their completion dates using `localStorage`.
- Preserves the selected theme between visits.
- Works without an account, server, or API key.

## 🚀 Getting Started

### Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/bloom-journal.git
   ```

2. Open the project folder:

   ```bash
   cd bloom-journal
   ```

3. Open `index.html` in your browser.

No package installation or build process is required.

### Deploy with GitHub Pages

1. Push `index.html` to the root of your GitHub repository.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Choose the `main` branch and `/(root)` folder.
5. Save and wait for the deployment to finish.

Your website will be published at:

`https://YOUR-USERNAME.github.io/bloom-journal/`

## 🔐 Privacy & Limitations

- Journal data is stored locally in the browser.
- There is no account system, cloud synchronization, or automatic backup.
- Data may be lost if browser storage is cleared.
- Other people using the same browser profile may be able to access locally stored entries.
- This project is intended for personal journaling and is not a secure storage system for highly sensitive information.
